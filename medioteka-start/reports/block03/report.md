# Отчёт по блоку

**ФИО, группа, напарник:** Федосеев Матвей, ИС35, Федосов Никита
**Номер блока:** 3. Сравнение браузеров и производительности
**Цель:** Научиться сравнивать возможности браузеров и проводить воспроизводимые измерения производительности.
**Окружение и версии:** Windows 10/11, Python 3.13.1, Яндекс Браузер (версия актуальная), Microsoft Edge (версия актуальная).
**Исходный SHA:** `a2e8c54e6eb56cd702a61b23359249799864b61c`

**Выполненные действия:**
1. Выполнены четыре функциональных сценария в двух браузерах (Яндекс и Edge).
2. Проведены замеры времени загрузки страницы (5 раз в каждом браузере) с отключенным кешем в DevTools.
3. Проведены замеры памяти (3 раза в каждом браузере) при открытых 5 одинаковых вкладках через Диспетчер задач Windows.
4. Рассчитаны медианы для времени загрузки и памяти.

**Исходные данные и наблюдения:**
*   **Время загрузки:** В Яндексе медиана составила 47 мс, в Edge — 57 мс. Разница незначительна и сопоставима с разбросом (от 43 до 64 мс). Оба браузера показали высокую скорость.
*   **Память:** В Яндексе медиана составила 435 МБ, в Edge — 650 МБ. Edge потребляет значительно больше оперативной памяти при одинаковом количестве вкладок.
*   **Функции:** Оба браузера поддерживают восстановление вкладок и работу с паролями. В Edge встроенная защита от рекламы эффективнее, чем в Яндексе.

**Проблемы и запросы в GitFlic:**
В рамках данного блока проблемы не создавались, так как проводилось только исследование инструментов.

**Полученные результаты:**
Таблицы `features.csv` и `performance.csv` заполнены. Рассчитаны медианы. Все исходные значения сохранены.

**Ограничения проверки:**
Замеры проводились на одном компьютере и в локальной сети (localhost). Результаты не могут быть экстраполированы на другие сайты или компьютеры с другим железом. Влияние фоновых процессов Windows не исключено.

**Личный вклад:**
Самостоятельно выполнены замеры в двух браузерах, собраны и обработаны данные, рассчитаны медианы, заполнены CSV-файлы.

**Вывод, подтверждённый данными:**
Для повседневной работы (учебы) Яндекс Браузер является более оптимальным выбором, так как потребляет меньше оперативной памяти (435 МБ против 650 МБ у Edge) при сопоставимой скорости загрузки (47 мс против 57 мс). Для исследования веб-приложений Edge может быть удобнее из-за более мощных встроенных инструментов разработчика (DevTools).
