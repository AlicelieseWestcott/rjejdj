**Номер блока:** 5. Удобство и персонализация браузеров
**Цель:** Научиться оценивать удобство браузеров по действиям пользователя и обосновывать персонализацию рабочего места.
**Окружение и версии:** Windows 11, Python 3.13.1, Яндекс Браузер, Microsoft Edge.
**Исходный SHA:** `a2e8c54e6eb56cd702a61b23359249799864b61c`

**Выполненные действия:**
1. Определены 5 сценариев для оценки удобства.
2. Выполнены сценарии в двух браузерах с замером времени и количества действий.
3. Оценена читаемость светлой и темной темы.
4. Изучены разрешения для одного расширения (перед установкой).
5. Сформирована рекомендация для учебного компьютера.

**Исходные данные и наблюдения:**
*   В большинстве сценариев Яндекс Браузер оказался быстрее (например, поиск разрешений: 4.59 сек против 6.52 сек в Edge).
*   Исключение составил сценарий с расширениями: в Edge установка и удаление заняли 5.84 сек, а в Яндексе — 8.09 сек (магазин расширений загружался дольше).
*   Светлая и темная темы в обоих браузерах читаемы, контрастность текста достаточная.

**Проблемы и запросы в GitFlic:**
В рамках блока проблемы не создавались, так как проводилось только исследование удобства.

**Полученные результаты:**
*   Таблица `usability.csv` заполнена (5 сценариев × 2 браузера).
*   Выявлены затруднения: в Edge настройки разрешений находятся глубже в меню, чем в Яндексе.
*   Рекомендация для учебного компьютера: использовать Яндекс Браузер для повседневных задач (быстрее поиск настроек), но для работы с расширениями удобнее Edge.

**Ограничения проверки:**
Выборка ограничена двумя участниками (если работали в паре). Время выполнения зависит от навыка пользователя. Личные предпочтения (например, привычка к интерфейсу) могут влиять на результат.

**Личный вклад:**
Самостоятельно выполнены замеры времени и действий, оценена читаемость тем, изучены разрешения расширения, подготовлены выводы и рекомендации.

**Вывод, подтверждённый данными:**
Удобство браузера зависит от сценария. Яндекс быстрее в базовых настройках, Edge — в работе с расширениями. Для учебного компьютера рекомендуется установить Яндекс Браузер как основной, но не запрещать Edge для специфических задач.
